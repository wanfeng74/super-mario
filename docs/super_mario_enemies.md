# 超级马里奥兄弟 (FC/NES) 全敌人图鉴

> 整理自全部 32 个关卡中出现的所有敌方单位与陷阱型障碍

---

## 一、地面行走类

### 1. 栗子仔（Little Goomba）
- **外观**：棕色蘑菇状小圆脸，有脚
- **首次出现**：World 1-1
- **出现关卡**：全游戏几乎所有地面关
- **行为/作用**：
  - 从右向左直线走动，遇到悬崖会直接掉下去（绿壳龟同款AI）
  - 是玩家遇到的第一个敌人，用来熟悉"踩踏"操作
  - 成群出现时形成压迫感
- **消灭方式**：踩踏 / 火焰花 / 无敌星 / 龟壳
- **分值**：100 分

### 2. 绿诺库龟（Koopa Troopa - Green）
- **外观**：绿色龟壳，黄色身体
- **首次出现**：World 1-1
- **出现关卡**：多数地面关
- **行为/作用**：
  - 直线行走，会走下悬崖边缘
  - 踩一下会缩入龟壳，龟壳可以被踢飞，连续撞击其他敌人
  - 提供"龟壳弹射"战术机制
- **消灭方式**：踩两下（先缩壳再踢飞）/ 火焰花 / 无敌星
- **分值**：100 分

### 3. 红诺库龟（Koopa Troopa - Red）
- **外观**：红色龟壳，黄色身体
- **首次出现**：World 1-2
- **行为/作用**：
  - 比绿龟聪明，**不会走下平台边缘**，会在平台上往返巡逻
  - 守在窄平台上时形成"守门员"式障碍
- **消灭方式**：同绿龟
- **分值**：100 分

### 4. 绿飞龟（Koopa Paratroopa - Green）
- **外观**：带白色翅膀的绿龟
- **首次出现**：World 1-3
- **行为/作用**：
  - 在空中上下跳跃飞行，轨迹不规则
  - 踩一下会失去翅膀变成普通绿龟
  - 在平台跳跃关增加空中障碍
- **消灭方式**：踩两下 / 火焰花
- **分值**：400 分（直接打死）

### 5. 红飞龟（Koopa Paratroopa - Red）
- **外观**：带翅膀的红龟
- **首次出现**：World 3-3
- **行为/作用**：
  - 在空中做直线跳跃，比绿飞龟更难预判
  - 踩一下变红龟
- **消灭方式**：同绿飞龟
- **分值**：400 分

## 二、管道植物类

### 6. 食人花（Piranha Plant）
- **外观**：绿色茎干，白色头部带红色斑点，大嘴
- **首次出现**：World 1-2
- **行为/作用**：
  - 从绿色水管中反复探出脑袋，开合嘴巴，再缩回去
  - **不能踩踏**，踩到会受伤
  - 玩家站在水管上方时它不会出来——逼你要么绕路、要么快速通过
  - 设计目的：阻止玩家无脑钻水管抄近路
- **消灭方式**：火焰花 / 无敌星（踩踏无效）
- **分值**：200 分

---

## 三、水下类

### 7. 墨鱼（Blooper）
- **外观**：白色鱿鱼状，有触手
- **首次出现**：World 2-2
- **出现关卡**：2-2、7-2、8-4
- **行为/作用**：
  - 在水中以**Z字形/锯齿形**轨迹追踪玩家
  - 速度不快但会主动追击，水下关的主要压迫来源
  - 水面上也会出现（如 2-3 桥上）
- **消灭方式**：火焰花 / 无敌星（水下不能踩）
- **分值**：200 分

### 8. 跳跳鱼（Cheep Cheep）
- **外观**：红色/橙色小鱼
- **首次出现**：World 2-2
- **出现关卡**：2-2、2-3、7-2、8-4
- **行为/作用**：
  - 水下：直线游动或波浪形游动
  - 水面：从桥下跃出，抛物线轨迹飞过
  - 2-3 关大量从水面跳出，逼玩家不停跑动
- **消灭方式**：火焰花 / 无敌星 / 踩踏（跳出水面时）
- **分值**：200 分

## 四、投掷/远程类

### 9. 锤子龟（Hammer Bro）
- **外观**：戴头盔的乌龟，手持两把锤子
- **首次出现**：World 3-1
- **出现关卡**：3-1、5-2、7-1、8-3、8-4（成对出现）
- **行为/作用**：
  - 成对出现，站在砖块上**交替上下跳跃并投掷锤子**
  - 锤子呈抛物线飞行，覆盖空中和地面
  - 停留太久会主动追玩家
  - 游戏中最危险的杂兵之一，需要精准跳跃躲避锤子
- **消灭方式**：踩踏 / 火焰花 / 龟壳
- **分值**：1000 分

### 10. 云龟（Lakitu）
- **外观**：戴眼镜的乌龟，坐在白云上
- **首次出现**：World 4-1
- **出现关卡**：4-1、6-1、8-2
- **行为/作用**：
  - 漂浮在屏幕上方，跟随玩家移动
  - 不断向下扔刺龟蛋，蛋落地孵化成 Spiny
  - 屏幕上最多同时存在 5 个敌人（含自身）
  - 打死它 40 秒后会重新出现
  - 设计目的：制造持续压力，逼玩家快速前进
- **消灭方式**：踩踏 / 火焰花 / 龟壳
- **分值**：800 分

### 11. 刺龟（Spiny）
- **外观**：黑色圆身，背上满是尖刺
- **首次出现**：World 4-1
- **行为/作用**：
  - 从 Lakitu 扔下的蛋中孵化，孵化后左右走动
  - **绝对不能踩**，踩到直接受伤
  - 只能用火焰花、龟壳或无敌星消灭
  - 是"不能踩"机制的教学敌人
- **消灭方式**：火焰花 / 龟壳 / 无敌星（踩踏无效）
- **分值**：200 分

### 12. 子弹比尔（Bullet Bill）
- **外观**：黑色子弹头，有眼睛
- **首次出现**：World 5-1
- **出现关卡**：5-1、6-2、8-2、8-3
- **行为/作用**：
  - 从右侧的龟形炮筒中水平发射，直线飞行
  - 速度快，一旦发射不会停下
  - 可以踩灭，也可以躲进凹坑里避开
  - 设计目的：在长直道上制造突然的横向威胁
- **消灭方式**：踩踏 / 龟壳 / 无敌星
- **分值**：200 分

## 五、城堡陷阱类（非生物）

### 13. 帕拉火球（Podoboo）
- **外观**：橙红色火球
- **首次出现**：World 1-4
- **出现关卡**：所有城堡关（X-4）
- **行为/作用**：
  - 从岩浆池中垂直向上跃起，再落回岩浆
  - 跃起高度固定，需要卡时机跳跃
  - 是城堡关的标志性障碍
- **消灭方式**：不可消灭（无敌星状态下接触安全）
- **分值**：无

### 14. 火焰棒（Fire Bar）
- **外观**：一串连成线的火球，固定在轴上
- **首次出现**：World 2-4
- **出现关卡**：2-4、3-4、5-4、6-4、8-4
- **行为/作用**：
  - 以固定速度**旋转**，像时钟指针一样扫过平台
  - 有的是半圈旋转（半圆），有的是整圈
  - 需要卡旋转节奏通过
  - 迷宫城堡的核心机制障碍
- **消灭方式**：不可消灭
- **分值**：无

## 六、BOSS 级

### 15. 库巴（Bowser）
- **外观**：大型龟龙，喷火，挥锤
- **首次出现**：World 1-4
- **出现关卡**：每世界第 4 关（1-4 ~ 8-4）
- **行为/作用**：
  - 坐在桥上，不断喷火球，偶尔挥锤跳跃
  - **前 7 个"库巴"都是假货**——分别由不同敌人假扮（1-4是栗宝宝、2-4是龟、3-4是锤头龟……），8-4 才是真库巴
  - 击败方式：要么踩它头顶的斧头砍断桥，要么用火球打死
  - 打死假库巴后会露出真身（一只小杂兵）
  - 设计目的：每关世界的终点考验，综合检验前面积累的操作
- **消灭方式**：触斧 / 火焰花（8-4 真库巴必须触斧或火）
- **分值**：无（通关奖励）

---

## 七、其他

### 16. 硬壳虫（Buzzy Beetle）
- **外观**：黑色圆壳甲虫
- **首次出现**：World 8-4
- **行为/作用**：
  - 类似龟，但**火焰花打不死**（火焰会弹开）
  - 踩踏后变壳可以踢
  - 只在最终关出现，作为最终考验
- **消灭方式**：踩踏 / 龟壳 / 无敌星（火焰花无效）
- **分值**：200 分
