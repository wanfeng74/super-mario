**关键行为特征（改 bug 判定依据）：**
- 栗子仔、绿龟、硬壳虫：**走到平台边缘会直接走下去**；红龟：边缘掉头。
- 绿飞龟=水平波浪飞（会越过平台）；红飞龟=原地垂直跳（不横移）。
- 踩飞龟→失去翅膀变普通龟（绿飞龟→绿龟、红飞龟→红龟），得 400 分后再踩得 100 分。
- 食人花：玩家站在管顶时不弹出；弹出周期约 3 秒（升 0.4s / 露 1.6s / 降 0.4s / 藏 1s）。
- 刺龟、硬壳虫：火焰花无效（刺龟不可踩，硬壳虫踩→壳可踢）。
- 云龟在场时不断扔蛋孵化刺龟，屏幕同时最多 5 个敌人。
