## 一、项目概述

超级马里奥（有道词典笔版）是一款面向**有道词典笔 falcon UI 平台**的横版卷轴平台跳跃游戏，完整复刻 FC 版《超级马里奥兄弟》的核心玩法，并根据词典笔硬件的触摸屏、低性能与 QuickJS 运行环境做了深度适配。

| 项目项 | 说明 |
|---|---|
| 项目名称 | 超级马里奥（有道词典笔版） |
| 目标平台 | 有道词典笔 falcon UI（QuickJS / 极简 Canvas / 纯触摸） |
| 当前版本 | v2.1.3（2026-09-19 发布） |
| 当前关卡 | 1-1 ~ 8-4 共 **32 关**（完整可玩，8 大世界全部打通） |
| 内容资产 | 原版 32 关关卡截图（World 1-1 ~ 8-4）、16 种敌人图鉴 |
| 包格式 | AMR（aiot-cli 打包，appid 8001865309000002） |
| 存档位置 | `/userdisk/database/mario_save.json`，共 3 个存档位 |

## 二、设计思路

### 2.1 玩法设计

针对词典笔"无键盘、单屏触摸、低性能"的硬件条件，玩法设计遵循"极简操作、渐进挑战、单屏可玩"三条原则。

| 玩法要素 | 设计说明 |
|---|---|
| 三段触摸区 | 屏幕左侧按住左移、中间按住右移、右侧按住跳跃；无虚拟按键，避免遮挡画面 |
| 敌人机制 | 踩敌人消灭（正上方踩踏判定），顶问号块出金币，顶砖块打碎得分 |
| 成长系统 | 蘑菇变大、火花花变火焰、星星无敌 |
| 生命与结算 | 3 条命；掉坑 / 被敌人碰到 / 时间耗尽扣命；100 金币 +1 命；到达旗杆过关 |
| 暂停菜单 | 右上角触摸暂停：继续 / 保存进度 / 返回标题 / 删除存档 |
| 存档界面 | 主页标题面板 + 三张存档卡横排；切后台 / 退出自动保存 |
| 调试模式 | 关于页连续点击版本号 10 次进入：可选关（1-1 ~ 8-4）、无敌模式，仅本次运行生效 |

### 2.2 系统架构

采用"页面层 + 服务层"两层结构：Vue 页面负责生命周期、触摸输入与画布上下文获取；游戏逻辑全部收敛在纯 JS 服务层，便于脱离 UI 独立测试与复用。

```
ui/
  src/app.js                  # setViewPort(960) + BasePage 注册
  src/app.json                # 页面注册（仅 index）
  src/base-page.js            # 页面基类：定时器统一释放
  src/pages/index/index.vue   # 游戏页面（标题/存档位/暂停/触摸输入）
  src/services/game/levels.js # 关卡数据（段式描述, 1-1~8-4 共32关）
  src/services/game/engine.js # Canvas 引擎（物理/碰撞/敌人/渲染/离屏贴图缓存）
  src/services/game/sprites.js# 像素贴图精灵表
  src/services/save.js        # 3 存档位持久化
  src/services/version.js     # 版本号
```

| 模块 | 职责与设计要点 |
|---|---|
| index.vue | 页面层唯一入口：onShow 生命周期内获取 canvas 2d 上下文并注入引擎；触摸事件（touchstart/touchmove/touchend）映射为输入状态；主页存档卡界面 |
| engine.js | 核心引擎：物理（重力/跳跃/空气墙）、碰撞（踩怪判定）、敌人 AI、渲染；使用离屏 canvas 缓存贴图，drawImage 快路径替代逐帧 fillRect |
| levels.js | 关卡数据采用"段式描述"：每段声明地形、敌人、道具与产出，引擎按段装配；新增关卡只改数据不动引擎 |
| sprites.js | 原版 SMB 像素贴图精灵表（角色/砖块/管道/问号块/敌人），v1.2.2 起全部替换为原版像素风格 |
| save.js | 3 存档位持久化，读写 `/userdisk/database/mario_save.json`；切后台 / 退出自动保存 |

### 2.3 性能设计

falcon 设备主频低，全屏逐像素绘制必然卡顿。性能策略按优先级排列：

1. 离屏 canvas 缓存贴图：绘制一次、反复 drawImage，比逐帧 fillRect 快 10 倍以上
2. 控制每帧 fillRect 调用次数，避免全屏重绘
3. 贴图压缩：缩小分辨率、减少颜色数
4. 禁止每帧创建新对象，规避垃圾回收卡顿
5. 帧率用 `setInterval(16)` 约 60fps，dt 用 `Date.now()` 差值计算，不假设固定帧间隔

## 三、适配方案

### 3.1 平台约束总览

falcon UI 是一个高度裁剪的运行环境，与浏览器差异巨大。适配的核心原则：**只使用平台确认支持的 API，其余一律用替代实现或显式规避**。

| 维度 | 平台约束 |
|---|---|
| 脚本引擎 | QuickJS（version=20200705），仅支持 ES5；禁用 const/let/箭头函数/class/展开运算符 |
| Canvas | 极简实现，只保留 fillRect / fillText / drawImage / fillStyle / font / textAlign |
| 输入 | 仅 touchstart/touchmove/touchend/touchcancel；无鼠标事件（浏览器预览才有） |
| 存储 | 无 localStorage / fs 模块；文件读写走 panet.readFile / panet.writeFile，目录需自行创建 |
| 性能 | 主频低，全屏 fillRect 每帧几百次即卡顿 |

### 3.2 Canvas 适配

| 约束 | 后果 | 替代方案 |
|---|---|---|
| getContext('2d') 必须在页面层获取 | 引擎内获取可能返回 null | index.vue 的 onShow 里获取 ctx 后传入引擎 |
| 递归调用 getContext | 无限递归，栈溢出黑屏重启 | 失败直接返回 null，引擎用 `if (!this.ctx) return` 保护 |
| ctx.textBaseline | 直接崩溃，渲染中断 | 不设置 textBaseline，手算 y 偏移 |
| ctx.strokeRect | 崩溃，后续 fillText 不执行 | 用 4 条 fillRect 画边框 |
| ctx.arc() / 复杂路径 | 可能不支持 | 尽量用 fillRect 拼几何 |
| 自定义字体文件 | 不支持 | `font = 'bold 14px sans-serif'`；textAlign 只用 left / center |

### 3.3 触摸输入适配

- touchend 可能不带坐标，必须清空全部输入状态（left/right/jump 置 false）
- touches 数组在部分固件版本不存在，需兼容 changedTouches：

```js
var t = ev.touches && ev.touches[0] ? ev.touches[0] : ev.changedTouches[0]
```

- 同时按方向键 + 跳跃键可能被系统打断，属设备系统级问题，应用层无法解决；三段触摸区设计让用户尽量不同时按

### 3.4 存档适配

- 路径固定为 `/userdisk/database/mario_save.json`（`<app_name>_save.json` 规则）
- 文件系统初始化时机不确定：引擎构造函数里禁止直接调用文件 API，必须 try/catch 包裹，失败回退默认值
- 3 个存档位；v2.1.3 起真机持久化更稳定，**切后台 / 退出自动保存**
- 主页界面：标题面板 + 三张存档卡横排，直接选档进入

### 3.5 语法适配（QuickJS / ES5）

```js
// ✅ 可以用
var x = 1
function foo() {}
Array.prototype.forEach.call(arr, function() {})

// ❌ 不能用
const x = 1
let y = 2
() => {}
class Foo {}
// 展开运算符 ... 不可用；map 可用
```

> ⚠️ **quickjs.version 必须保持 `"20200705"`**，该值对应 qjsc 二进制名；**不要改成 app 版本号**，否则打包报错 `Can't find qjsc`。顶层 `version` 才是 app 版本号，两者分开。

## 四、打包方法

### 4.1 环境要求

- Node.js + pnpm（工程为 pnpm 管理，锁文件 pnpm-lock.yaml）
- aiot-cli（打包工具，随工程依赖提供）
- 真机安装需 adb 与 miniapp_cli（词典笔固件工具）

### 4.2 本地预览（浏览器调试）

```bash
pnpm install -C ./ui
pnpm -C ui preview
```

浏览器预览快捷键：方向键移动、空格 / ↑ 跳、P / Esc 暂停。预览环境有鼠标事件，与真机纯触摸不同。

### 4.3 生产打包（生成 AMR）

```bash
pnpm -C ui package   # 内部执行 aiot-cli -c -q -p
```

产物为 AMR 文件，命名规则：`<appid>.<主>_<次>_<修订>.amr`，当前版本为 `8001865309000002.2_1_3.amr`。

### 4.4 真机安装

```bash
adb push 8001865309000002.2_1_3.amr /data/local/tmp/
adb shell "miniapp_cli install /data/local/tmp/8001865309000002.2_1_3.amr"
adb shell "miniapp_cli start 8001865309000002"
```

### 4.5 打包配置红线

| 配置项 | 规则 |
|---|---|
| quickjs.version | 固定为 `20200705`（对应 qjsc 二进制名），禁止改成 app 版本号 |
| appid | 每个 app 独立 appid（8001865309000002 / 3 / 4），不能与其他 app 重复 |
| 版本号 | 顶层 version 为 app 版本，随发布递增；修改后 AMR 文件名同步更新 |

## 五、关卡模式

### 5.1 关卡数据模型

关卡在 levels.js 中以**段式描述**组织：每个关卡由若干段组成，每段声明地形元素、敌人、道具与产出规则，引擎按段装配渲染。段式设计的收益：

- 新增 / 调整关卡只改数据文件，不动引擎代码
- 敌人、砖块、问号块、管道等要素均为可复用声明
- 关卡长度、难度曲线通过段的数量与排列控制

**数据层关键约定**（来自踩坑记录）：

- 怪物 y 坐标必须贴地（`GROUND_Y - 1`），不能悬空
- 问号块只能产出一次（`used: false/true`），不能无限出金币
- 顶部空气墙：p.y 不允许小于 0，超出即钳制
- 长按跳跃上限 280ms，不能无限高
- 踩怪判定：只有从正上方踩才算踩死，侧面碰到算受伤；判定范围要宽松（y 方向有重叠范围）
- 悬空平台间距统一为 3-4 格，确保玩家可跳上（v2.1.3 起）

### 5.5 后续维护指引

32 关已完整，后续改动遵循以下约定：

1. 新增 / 调整关卡在 levels.js 中按段式语法修改（复用现有地形 / 敌人 / 道具声明），对照 World 截图与原版布局
2. 新敌人优先复用现有 AI 类别；确需新机制时在 engine.js 增加行为分支，并保持 ES5 语法
3. 新敌人在对应关卡中的分布参照 super_mario_enemies.md 的逐关数据
4. 任何发布前同步更新版本号、AMR 文件名与调试模式可选关范围
5. 真机验证新关卡帧率，必要时压缩贴图或减少同屏敌人

## 六、开发踩坑记录（必读）

以下为项目在有道词典笔 falcon UI 平台踩过的全部坑，后续开发务必规避，按类别归档：

| 类别 | 踩坑要点 |
|---|---|
| 打包配置 | quickjs.version 不能改成 app 版本号；appid 必须唯一 |
| Canvas 渲染 | getContext 必须在页面层；禁止递归 getContext；不支持 textBaseline / strokeRect / arc；字体只用 sans-serif，textAlign 只用 left / center |
| 触摸输入 | 纯触摸无鼠标；touchend 可能无坐标需全清空；touches 可能不存在需兼容 changedTouches；方向 + 跳跃同按可能被系统打断 |
| 性能 | 设备主频极低；用离屏缓存 + drawImage；控制每帧 fillRect 次数；不每帧新建对象；setInterval(16) + Date.now() 差值 |
| 存档 | 路径 `/userdisk/database/<app_name>_save.json`；无 localStorage / fs；用 panet.readFile / writeFile；目录需自建；构造函数里禁止直接调文件 API，try/catch 兜底；v2.1.3 起切后台 / 退出自动保存 |
| 游戏逻辑 | 顶部空气墙钳制；长按跳跃上限 280ms；踩怪从正上方判定且要宽松；怪物贴地；问号块只出一次；悬空平台间距 3-4 格 |
| 语法 | 纯 ES5：禁用 const / let / 箭头函数 / class / 展开运算符 |

**v2.1.3 已修复问题**（开发时曾踩过）：踩怪碰撞判定、锤子龟/云龟渲染、红飞龟配色、食人花弹出间隔（统一 3 秒）、熔岩球残留、调试模式关卡范围。
